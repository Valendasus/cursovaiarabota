# Розничная торговля продуктами в сети магазинов у дома

Прототип регистрирует продажи по партиям, показывает товары с истёкшим и приближающимся сроком годности и рассчитывает пополнение для каждого магазина.

## Запуск Spring Boot через Docker Compose

Из корня репозитория:

```sh
docker compose up --build -d
curl -fsS http://localhost:8080/actuator/health
```

Когда проверка вернёт `{"status":"UP"}`, откройте [интерфейс](http://localhost:8080/) и выберите магазин и дату. В нём доступны продажа, контроль сроков и расчёт пополнения.

Продажа фиксирует списание по партиям. Проверка сроков выполняется по запросу сотрудника, а расчёт пополнения выдаёт рекомендуемое количество для заявки. Диаграммы также показывают действия сотрудника с товаром и оформление заявки.

Тот же сценарий в учебном магазине № 1 можно выполнить через HTTP:

```sh
curl -fsS http://localhost:8080/api/stores/1/sales \
  -H 'Content-Type: application/json' \
  -d '{"date":"2026-11-26","items":{"MILK":5,"BREAD":1}}'
curl -fsS 'http://localhost:8080/api/stores/1/expiry-alerts?date=2026-11-26&days=2'
curl -fsS 'http://localhost:8080/api/stores/1/replenishment?date=2026-11-26'
```

На свежей базе продажа возвращает HTTP 201 и итог `50500` копеек. После неё сервис предлагает пополнить молоко на 9 упаковок и хлеб на 6. Если одной из позиций не хватает, сервис возвращает HTTP 409 и сохраняет остатки всей корзины.

SQLite хранится в томе `inventory-data`. Команда `docker compose down` останавливает контейнер и сохраняет продажи в томе. Для запуска на другом порту задайте `INVENTORY_PORT`, например `INVENTORY_PORT=8081 docker compose up -d`.
