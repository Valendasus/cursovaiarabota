# Розничная торговля продуктами в сети магазинов у дома

Учебный прототип учитывает остатки по партиям в отдельных магазинах. Он распределяет продажи по правилу FEFO, выделяет партии с истёкшим или приближающимся сроком годности и рассчитывает рекомендуемое пополнение.

## Реализация

В [папке «Прототип»](<Прототип/README.md>) находятся код на Python и Java, схема SQLite, демонстрационные данные и тесты. Там же описаны команды запуска.
